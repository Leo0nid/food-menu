# Продукт

## Цель MVP

Гость ресторана открывает цифровое меню, привязанное к конкретному
столу, выбирает блюда и отправляет заказ.

## Способы открытия меню

### QR-код

Гость сканирует QR-код, содержащий ссылку конкретного стола.

### Планшет ресторана

На планшете заранее открыта страница конкретного стола. Гость сразу
видит меню без сканирования QR-кода.

Оба способа используют один адрес:

`/table/:token`

## Главный сценарий

1. Открывается ссылка конкретного стола.
2. Сервер определяет ресторан и стол по токену.
3. Загружается меню ресторана.
4. Гость добавляет блюда в корзину.
5. Гость отправляет заказ.
6. Заказ поступает администратору с указанием стола.
7. После завершения заказа корзина очищается.

## Возможности гостя

- просмотр меню;
- просмотр категорий и блюд;
- добавление блюд в корзину;
- изменение количества;
- отправка заказа;
- просмотр статуса заказа.

## Возможности администратора

- создание ресторана;
- создание и отключение столиков;
- получение ссылки конкретного стола;
- создание QR-кода из ссылки;
- открытие ссылки на планшете;
- просмотр заказов;
- изменение статуса заказа;
- управление меню.

## Важное правило

QR-код не является обязательным. Он только содержит ссылку стола.
Заказ всегда привязывается к столу и ресторану через токен ссылки.
